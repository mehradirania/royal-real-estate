# Royal Real Estate Demo

نسخه اولیه و قابل نمایش سایت آژانس املاک رویال با طراحی RTL و responsive.

## امکانات نسخه دمو
- صفحه اصلی مشابه طرح تأییدشده
- طراحی موبایل و دسکتاپ
- نمایش آگهی‌ها
- پنل مدیریت `/admin.html`
- افزودن، ویرایش و حذف آگهی
- انتخاب تصویر از گوشی یا وارد کردن URL تصویر
- فعال/غیرفعال کردن نمایش آگهی در «پیشنهاد رویال»
- ویرایش شماره تماس
- ویرایش آدرس و متن تماس
- افزودن، حذف و ویرایش لینک شبکه‌های اجتماعی
- اطلاعات در LocalStorage مرورگر ذخیره می‌شوند

## ورود دمو
نام کاربری: `admin`
رمز عبور: `admin123`

## نکته مهم برای نسخه نهایی
این نسخه برای Demo و ارائه به مشتری ساخته شده است. LocalStorage امنیت واقعی برای پنل ادمین فراهم نمی‌کند. برای تحویل نهایی باید Backend + Database + احراز هویت امن + فضای ذخیره‌سازی تصاویر اضافه شود.
